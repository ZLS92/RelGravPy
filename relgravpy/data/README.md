# Tamura T87 coefficient dataset

File: tamurahw.dat (1,200 harmonic constituents)

Original potential: Y. Tamura (1987), A harmonic development of the
tide-generating potential, Bulletin d'Informations Marees Terrestres 99,
6813–6855.

The distributed HW95-normalized coefficient file was transformed by
Hans-Georg Wenzel in 1995 and is reproduced from the PyGTide/ETERNA
data distribution at:
https://github.com/hydrogeoscience/pygtide/blob/master/pygtide/commdat/tamurahw.dat

PyGTide's distribution uses the Mozilla Public License 2.0.
A copy is bundled alongside the data (LICENSE-MPL-2.0.txt).
This is only a redistributed static table; RelGravPy imports **no** code
or runtime dependency from PyGTide.

Note: the standalone RelGravPy predictor remains under validation.
Prediction of ocean-loading, pole tides, and LOD is out of scope.
